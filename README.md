# HOTEL-MOLINERA

## Ejecución

Desde la carpeta del proyecto:

```bash
cd frontend
```

Ahora hay que navegar a la carpeta frontend:

```bash
npm install
```

Instalar dependencias:

```bash
npm install dotenv cors react-router-dom
```

Finalmente iniciar el servidor:

```bash
npm run dev
```
