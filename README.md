# HOTEL-MOLINERA

## Ejecución

Desde la carpeta del proyecto:

```bash
cd frontend
npm install
npm run dev
```

## Construcción

Para generar la versión de producción:

```bash
npm run build
```

## Dependencias

Si no están instaladas, agregar:

```bash
npm install dotenv cors react-router-dom
```
